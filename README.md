# Smart-Feedback Backend API\n\n## Features\n- Submit feedback with auto sentiment analysis (Positive/Negative/Neutral)\n- View all feedback\n- MongoDB + Express + CORS for https://smart-feedback-client.vercel.app\n\n## Quick Start (Local)\n\n1. Copy `.env.example` to `.env`:\n   ```bash\n   copy .env.example .env\n   ```\n2. Add your MongoDB URI to `.env` (free: https://mongodb.com/atlas)\n3. Install & Run:\n   ```bash\n   npm install\n   npm start\n   ```\n   Server: http://localhost:5000\n\n**API Endpoints:**\n- `GET /` - Health check\n- `POST /api/feedback` - `{ \"content\": \"text\" }` → auto sentiment\n- `GET /api/feedback` - List all\n\n## Deploy Backend (Recommended: Render.com)\n1. Push code to GitHub\n2. render.com > New Web Service > GitHub repo\n3. Build: `npm install`\n4. Start: `node server.js`\n5. Environment: Add `MONGO_URI`\n\nGet backend URL (e.g., https://your-feedback.onrender.com) → share with frontend.\n\n## Connect Frontend\nVercel client https://smart-feedback-client.vercel.app now allowed via CORS.\n
